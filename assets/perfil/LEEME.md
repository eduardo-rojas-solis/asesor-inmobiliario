# Carpeta de la foto de perfil

Aquí está la fotografía de Eduardo: `foto-eduardo.webp`.

Para cambiarla, suba una foto nueva **con el mismo nombre**
(GitHub preguntará si quiere reemplazar la anterior).

- Formato: WEBP o JPG. Si usa JPG, cambie también el nombre en `index.html`.
- Tamaño recomendado: al menos 800 píxeles de ancho y menos de 500 KB.

Las instrucciones completas están en el README principal, sección «Cambiar la foto».
