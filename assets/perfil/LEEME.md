# Carpeta de la foto de perfil

Suba aquí la fotografía profesional de Eduardo con el nombre `foto-eduardo.jpg`.

- Formato recomendado: JPG o WEBP, vertical (proporción 4:5).
- Tamaño recomendado: unos 800 × 1000 píxeles y menos de 500 KB.

Las instrucciones completas están en el README principal, sección «Cambiar la foto».
